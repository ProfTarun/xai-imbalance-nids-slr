# Supplementary information: Explainable Deep Learning and Class-Imbalance Mitigation in Network Intrusion Detection: A Structured Review of Methods, Evaluation Practice and Reporting Gaps

**Authors:** Tarun Jangwal (corresponding author, tarun.24044@lpu.co.in) and Purva Pathania
Lovely Professional University, Phagwara, Punjab, India

**Journal:** Archives of Computational Methods in Engineering (Springer)

This repository holds the eight Online Resources (electronic supplementary material) of the review. Record identifiers carry the prefix R (for example R57) to distinguish them from reference numbers. They are the same files supplied to the journal with the manuscript. Citation details will be added here when the article is published.

## Files

| File | Online Resource | Content |
|---|---|---|
| [ESM_1.xlsx](ESM_1.xlsx) | 1 | Evidence dataset of the 192 included primary studies, one row per study: record identifier, reference number, evidence tiers, family labels, conflict flags, indicators, full-text status and the corrections made during revision |
| [ESM_2.xlsx](ESM_2.xlsx) | 2 | Screening status of the 254 unique records (decision and stage) |
| [ESM_3.xlsx](ESM_3.xlsx) | 3 | Eligibility-stage status of the records that entered eligibility assessment (201 of 206 listed; see the sheet notes) |
| [ESM_4.xlsx](ESM_4.xlsx) | 4 | Register of extraction conflicts and flags (mitigation, explanation, dataset identity, missing numeric results, generative-only components) |
| [ESM_5.xlsx](ESM_5.xlsx) | 5 | The 26 existing reviews and surveys, with their scope and coverage as recorded in the extractions |
| [ESM_6.xlsx](ESM_6.xlsx) | 6 | The 12 records unresolved at the eligibility step, with the full-text finding and decision for each |
| [ESM_7.zip](ESM_7.zip) | 7 | Scripts and input tables that reproduce every count, table and figure, and a comparison of original and recomputed indicator values (see `README.txt` inside the archive) |
| [ESM_8.pdf](ESM_8.pdf) | 8 | Completed PRISMA 2020 checklist |

Each spreadsheet has an **About** sheet (title, journal, authors, content notes) and a **Data** sheet.

## How to use

1. Click a file name above, then click **Download** (the arrow icon, top right of the file view).
2. Open `.xlsx` files in Microsoft Excel, LibreOffice Calc or Google Sheets, and `ESM_8.pdf` in any PDF reader.
3. For `ESM_7.zip`, extract the archive and read `README.txt`; it gives the order in which to run the Python scripts. The structured extraction file used as input is not redistributed; the derived tables are in `data/`.

To download everything at once, click the green **Code** button on the repository page and choose **Download ZIP**.
